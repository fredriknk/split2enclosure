# Security policy

## Supported versions

Security fixes are applied to the latest released version of
Split2Enclosure. Users should update through FreeCAD's Addon Manager when a
new version is available.

## Reporting a vulnerability

Please report suspected vulnerabilities through GitHub's private security
reporting for the repository. Include the affected Split2Enclosure and FreeCAD
versions, reproduction steps, and the potential impact. Please do not open a
public issue until a fix or safe disclosure plan is available.

You should receive an acknowledgement within seven days. Confirmed issues
will be addressed and disclosed as soon as practical.
